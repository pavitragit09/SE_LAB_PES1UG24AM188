# Jira Lab 2 — Feature Flag & Dynamic Config Manager

**Scenario:** Feature Flag & Dynamic Config Manager (FFDCM)

This repository contains the evidence and documentation for the Jira Scrum workflow completed for Lab 2.

## Scenario
Build/manage a feature-flag and dynamic-configuration system used by developers and IT operations. The Jira board is named **FFDCM board**.

## Jira work completed
- 6 Epics created
- 15 User Stories created and assigned to Epics
- Story Points assigned
- 2 Scrum sprints created and completed
- Sprint 1: 6 stories, 32 story points
- Sprint 2: 9 stories, 46 story points
- Total: 15 stories, 78 story points
- Stories progressed through To Do → In Progress → Done
- Comments added to work items
- Burndown charts captured for both sprints

## Six Epics
1. Feature Flag Management
2. Targeting & Rollouts
3. Environment Configuration
4. Feature Flag Evaluation & Audit
5. SDK Synchronization
6. Performance, Security & Reliability

## Sprint goals
**Sprint 1:** Implement the core feature flag creation and evaluation workflow.

**Sprint 2:** Complete SDK synchronization, targeting, auditing, and system reliability capabilities.
