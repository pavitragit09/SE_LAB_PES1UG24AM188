# SE Lab 1 — Requirements Engineering & UML Use-Case Modelling

**Problem Statement #43: Feature Flag & Dynamic Config Manager**
A centralized configuration and feature toggling platform supporting percentage-based user cohort rollouts, environment overrides, and real-time client SDK flag synchronization.

**Actors:** Software Engineer, Release Manager
